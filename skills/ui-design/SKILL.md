# Skill: UI Design and Accessibility

Use for public/admin visual work.

Checklist:

- define tokens before screens;
- design idle, selected, processing, success, error, and cancelled states;
- test 320px through wide desktop;
- keyboard alternatives for drag actions;
- focus visibility and restoration;
- ARIA live progress/errors;
- reduced motion;
- contrast on glass surfaces;
- stable layout with ads on/off;
- no ad/tool visual confusion.

Deliver: changed tokens/components, screenshots or browser observations, axe result, responsive result, and known limitations.
