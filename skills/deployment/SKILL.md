# Skill: Deployment and Rollback

Use for preview/production hosting.

Procedure:

- verify current provider terms and limits;
- verify framework/runtime compatibility;
- use frozen lockfile;
- validate environment and no secret leakage;
- test deep routes, PDF worker assets, headers, sitemap, robots, admin auth, and ads disabled state;
- record deployment ID and rollback path;
- test custom domain/canonical redirects;
- do not enable real ads until owner approval and policy readiness.
