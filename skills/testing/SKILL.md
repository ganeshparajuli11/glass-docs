# Skill: Testing and Release Evidence

Use for every feature/release task.

Required evidence depends on scope:

- lint and typecheck;
- unit tests for pure logic;
- semantic integration tests for PDFs;
- Playwright happy and failure path;
- axe checks;
- network interception for Local tools;
- responsive browser verification;
- performance/memory fixture for heavy tools;
- build/deployment smoke.

Classify failures P0–P3 and never ship P0/P1.
