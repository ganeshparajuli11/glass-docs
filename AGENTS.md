# Repository Instructions for Coding Agents

1. Read `START_HERE.md`.
2. Read `.ai/PROJECT_STATE.md`, `.ai/HANDOFF.md`, `.ai/TASK_BOARD.md`, `.ai/FILE_MAP.md`.
3. Work on one task ID only.
4. Use the role prompt under `.agents/` matching the task owner.
5. Do not scan the whole repository unless the current acceptance gate genuinely requires it.
6. Do not upload public user documents for Local tools.
7. Do not expose secrets in the client.
8. Do not put ads near upload/process/download controls.
9. Run targeted checks, then the acceptance gate.
10. Update `.ai` memory and output the compact completion report.

The full operating rules are in `07_AGENT_SYSTEM.md` and `08_DEVELOPMENT_LOOP_AND_HANDOFF.md`.
